Exponents illustrate the process of repeated multiplication of a number by itself. Exponents are depicted with a base value (a), and an exponent (n) at the top serving as the number of times the base is multiplied.



Expressions involving Exponents can be easily solved and simplified using the Laws of Exponents. Which involve the following:

  • Product Rule: If you multiply two exponents with the same bases, you add these exponents together.
  • Quotient Rule: You subtract the exponents if you divide the exponents instead.
  • Power of a Power: If you raise an exponent by a power, the result would be the base raised to the product of both powers.
  • Product/Quotient of a Power: If you multiply or divide two different bases with the same power, the result would be the product or quotient of both bases raised to their common exponent.
  • Zero Exponents: If the exponent is zero, it always equates to 1.
  • Negative Exponents: If the exponent is negative, make the exponent positive, turn it into a fraction while making the same value the denominator.
