# Math At Work - Bite-sized Math Topics Website
## About
<p align="center">
<img src="https://github.com/CianDaxGitHub/math-at-work-webproj/blob/main/images/bg/mathlogo.png" alt ="Math at Work logo" width="360" style="">
</p>

A small website created in 2024 that features four different Math lessons, each taken from the 1st to 4th quarter from the Grade 9 curriculum; and provides concise, bite-sized information for topics ranging from Quadratic Expressions to Trigonometry. Each lesson features two topics to learn from, containing images and explanations regarding their formulas and solutions. It also includes a short summary; and a short, read-only quiz to test your knowledge on both topics.

This small website project was created to fulfill the academic requirements for the University of Rizal System.
